# Reguły Domenowe: Portfolio Artystyczne

Projekt stanowi oficjalną stronę portfolio artystycznego dyrygenta, multiinstrumentalisty i aranżera.

---

## 1. Architektura i Technologie
- **Framework:** Astro 5 (Static Site Generation).
- **Styling:** Tailwind CSS + animacje CSS / fizyka Spring Lerp.
- **Treści:** Astro Content Collections ze ścisłą walidacją schematów Zod.
- **CMS:** Pages CMS (`docs/CMS.md`).

---

## 2. Standardy DevEx
Projekt bezwzględnie dziedziczy wszystkie reguły inżynieryjne (Zod, Result Object, Czystość Root, Zero Samowolki dla AI) zdefiniowane w:
👉 **[devex-standards](https://github.com/kacperczeczot/devex-standards)**
